# AI_LOG

Инструмент: OpenAI Codex (GPT-6); PDF прочитан через pypdf и просмотрен по страницам. Контекстом были запрос пользователя и требования тестового задания: копейки, промокод, рассрочка, идемпотентность, переходы статусов, вебхук и PostgreSQL.

## Ключевые запросы

1. «Реализуй тестовое FastAPI в D:\test\PaymentServiceFastAPI: чистая архитектура, ООП, SOLID, KISS/DRY, async, Docker и PostgreSQL».
2. «Извлеки требования из PDF, отдели обязательную часть от бонусов и выполни оба списка».
3. «Добавь pytest-сценарии для денег, графика, повторных ключей, статусов и 404».

## Что перепроверено

- Один SELECT по Idempotency-Key не защищает от гонки. Ключ сделан уникальным в БД, а конфликт вставки возвращает существующий платёж.
- float для графика может терять копейки; применяется divmod.
- Первый прогон тестов выявил, что JSON None записывался как JSON null при проверке, ожидавшей SQL NULL. Для schedule включён none_as_null=True; повторный прогон прошёл.

Проверка: 11 тестов pytest прошли, Ruff сообщил All checks passed. Docker Compose описан; запуск контейнеров не проверялся, потому что Docker daemon недоступен в среде.
